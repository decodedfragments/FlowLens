Privacy-first queue & occupancy analytics

See where queues form. Never who is in them.

FlowLens turns one ordinary webcam into a people counter for stores, clinics and venues. It measures entries and exits, queue waits and dwell time on the device itself, and keeps no faces, no video and no identities.

How it works

From camera frame to anonymous numbers in five steps

Every frame is processed in memory and discarded. Only aggregates leave the pipeline.

  1. Capture

    Grabs only the newest webcam frame and reconnects on its own if the camera drops.

    OpenCV · MJPG 720p

  2. Detect

    Finds people, and only people, with the COCO person class. No face model is loaded.

    YOLO11 · GPU fp16 or CPU

  3. Track

    Follows each person with a short-lived number. Lost tracks are re-linked by motion alone.

    ByteTrack · velocity gating

  4. Measure

    Door zones, counting lines and queue zones turn foot points into entries, exits and waits.

    dead-band · exit grace · alerts

  5. Publish

    Streams aggregates to the dashboard twice a second and saves a CSV row every minute.

    WebSocket · CSV · state.json
Built for real doorways

Counts that hold up when people walk fast

A laptop camera may see someone in only two or three frames as they come through a door. FlowLens counts on what it can observe reliably, not on a perfect track.

Door zones

A track that starts in the doorway is an entry. A track that ends there is an exit. One sighting of a person's feet in the zone is enough, and the zone checks the whole bottom edge of the person's box.

Dead-band lines

A crossing counts when a person is seen fully on one side of a thin band and later on the other side. That includes someone who jumps across between two frames. Standing on the line never counts.

Motion re-linking

When the tracker loses someone and issues a new ID, the new ID inherits the history if it appears where that person was heading. The search area scales with body size and speed. No appearance features are used.

Confirmations

A track must last 3 frames before it counts. Visits shorter than the minimum are ignored, zone exits get a 1-second grace period, and an alert must hold for 5 seconds before it opens.

From one camera to a whole venue

Many cameras, one site view

Each camera runs FlowLens on its own computer and keeps its video there. A FlowLens Hub collects only the numbers and shows the whole event, store or venue in one dashboard.

  1. Camera nodes

    One FlowLens per camera: a laptop, a mini PC, or several IP cameras on one GPU machine. Each node has its own doors, lines and zones.

    video stays on the node

  2. Aggregates only

    Nodes send counts, waits and a fading occupancy grid every 2 seconds, plus a record every minute. If the network drops they buffer, then catch up.

    HTTP · token · store-and-forward

  3. FlowLens Hub

    Shows people inside the site, entries and exits, occupancy per area, queues, movement between areas, alerts and trends.

    SQLite · CSV · optional PIN

No double counting

Each door or line is marked as a site entrance, as between areas (with from and to), or as ignored. People inside the site come from entrances only, so cameras with overlapping views never add up the same person twice.

Floor plan optional

Upload any image: a venue plan, a store layout or a sketch. Click four matching floor points per camera to place its heatmap and zones on the plan. With no plan, the hub shows a board of areas instead.

Privacy by design

The privacy contract, written into the code

FlowLens publishes its own guarantees at /api/privacy. These are not settings someone can forget to turn on. The pipeline has no path to do otherwise.

QuestionAnswerHow
Does it recognise faces or identities?NeverOnly a person detector is loaded. Re-linking uses position and speed, never appearance.
Does it record video?NeverEach frame lives in memory for one loop iteration. Nothing visual is written to disk.
Can I see the camera?AnonymisedThe live view blurs, pixelates or masks people before encoding, or turns off completely. It is served to this machine only.
What is saved?AggregatesPer-minute counts, wait statistics and anonymous events such as "Front door: entered". No IDs, coordinates or images.
Can small groups be singled out?Optional guardA k-threshold shows counts below k as "<k".

Run it

Five minutes on a laptop with a webcam

Python 3.10 to 3.12 on Windows, macOS or Linux. An NVIDIA GPU is optional but recommended for busy doorways.

The dashboard opens at http://localhost:8000. Draw a door, a line or a queue zone, click Save layout, and counting starts.

  1. Get the code
    git clone https://github.com/<you>/flowlens.git cd flowlens
  2. Create an environment and install
    python -m venv .venv # Windows: .\.venv\Scripts\Activate.ps1 source .venv/bin/activate pip install -r requirements.txt
  3. Start FlowLens
    python app.py # webcam 0 python app.py --source 1 # another camera or rtsp://…
