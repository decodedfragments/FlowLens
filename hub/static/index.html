Connect a camera

On each camera computer, open FlowLens → Site hub, and enter this address and token. Or start it from PowerShell:
Address
Token
A new token disconnects every camera until they are given the new one.

Floor plan optional

Any PNG, JPG or WebP works: a venue plan, a store layout, a booth map or a photo of a hand sketch. Without one, the hub shows a board of areas instead. After uploading, map each camera from its own FlowLens page (Floor plan mapping), or drag unmapped cameras onto the plan with Place cameras.

Dashboard PIN

Other devices (phones, other laptops) are asked for this PIN once - type any user name and the PIN. This computer never needs it, and cameras use the token instead.

Start a new event

Sets entries, exits and people inside back to zero from now. Earlier data stays in the database and the per-camera CSV.
